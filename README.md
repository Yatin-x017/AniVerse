Made for Web application Programming Project. This project uses public api (jikan api) to fetch anime data and create an web page for anime.
AniVerse finds the best next watch for you effortlessly.

API being used in this project is jikan API : https://jikan.moe/ 
URL : "https://api.jikan.moe/v4"
No Authenticiation required as it is an open source and free API.
I'm using Myanimelist (MAL) as my datasource.

Jikan API provides rich anime data including titles, synopses, episode counts, scores, genres, airing status, studios, trailers, and high-resolution cover art.

The planned features are:
1. Search
2. Filter
3. Sort
4. Anime cards (cover art for series)
5. Detail View
6. Top Anime
7. Currenlty airing
8. Dark/Light Mode
9. Watchlist ( if possible )

The tech I'll be using is HTML, CSS and javascript.

No install or build setup will be required.
Either localhost or vercel should work.
